 Customer-Churn-Analysis-PowerBI
Customer churn analysis dashboard using power BI and Dax.
## Project Overview
An interactive Power BI dashboard developed to analyze customer churn and identify key factors affecting customer retention.

 Tools & Technologies
- Power BI
- DAX
- Data Cleaning
- Data Visualization

##Key KPIs
- Total Customers: 6,687
- Churned Customers: 1,796
- Churn Rate
- Total Charges
- Service Calls

##Analysis
The dashboard analyzes customer churn based on:
- Contract Type
- Payment Method
- Gender
- State
- Churn Reason
- Churn Category

## Dashboard Features
- Interactive KPI Cards
- Slicers
- Bar Charts
- Donut Charts
- Treemap
- Map Visualization
- Summary Table

## Project Outcome
The dashboard helps identify important churn patterns and provides business insights that can support customer retention strategies.
